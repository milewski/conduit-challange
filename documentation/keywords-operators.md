# Keywords & Operators

## Keywords
- `for`, `in`, `on`, `->`, `<-`, `<<-`, `{`, `}`, `(`, `)`, `[`, `]`
- Node/module names are identifiers.

## Operators
- Assignment: `->`, `<-`, `<<-`
- Range: `..`
- Arithmetic: `+`, `-`, `*`, `/`, `^`
- String interpolation: `{ ... }` inside strings

See [References](./references.md) for operator definitions in the parser.
