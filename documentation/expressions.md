# Expressions

Expressions support numbers, strings, references, binary operations, and string interpolation.

## Examples
- Numbers: `42`, `3.14`
- Strings: `"hello"`, `"value: {x}"`
- References: `identifier.property`
- Binary operations: `(a + b) * c`
- String interpolation: `"{user} scored {score}"`

See [Examples](./examples.md) and [References](./references.md) for more.
